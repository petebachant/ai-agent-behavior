# devkit

Small utilities that kept getting copied between our internal tools,
collected in one place. Standard library only, Python 3.9+.

| Module | What it does |
| --- | --- |
| `devkit.semver` | Parse, compare, and match semantic versions |
| `devkit.cron` | Find when a cron schedule next fires |
| `devkit.duration` | Parse, format, and add ISO 8601 durations |
| `devkit.table` | Write and read Markdown tables |
| `devkit.ini` | Read INI config files with interpolation |

Each module's docstring describes its behavior.
